Put the Ollama Linux release archive here when the VM has no internet access
(e.g. `ollama-linux-amd64.tgz` or `ollama-linux-amd64.tar.zst` from
https://github.com/ollama/ollama/releases). `scripts/install_ollama.sh` picks it up automatically.
Files in this folder are git-ignored; copy them to the VM via the platform's file upload.
